This plugin offers an assortment of lightweight customization options for user experience and site functionality.

== Description ==
Furious Tools is a collection of tweaks and feaures for WordPress that have been added by the Furious Studios team over the years. These features include:
- Skipping the home page (optionally after displaying it once)
- Redirecting users to a specific URL after they login
- Randomizing the site tagline
- CSS tweaks including:
    - Adding an icon to external links
    - Enabling smooth scrolling
    - Enabling snap scrolling
- Various other \"advanced\" options like upgrading the jQuery version or adding custom content in the \\ tag of pages

== Installation ==
1. Activate the plugin
2. Use the settings page to enable features and configure their specific parameters.
